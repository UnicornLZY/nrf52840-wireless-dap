本目录包含经过硬件实测验证的最新正式发布固件，以及源码编译脚本的默认输出目标。

* **固件文件名**：`无线DAPLink_一键Bootloader_瓶颈诊断_AFH_R11.uf2`
* **应用起始地址**：`0x26000`（适配搭载 Adafruit S140 6.1.1 / nice!nano UF2 Bootloader 的 nRF52840 开发板）
* **固件大小**：300,032 字节（586 个 UF2 扇区块）
* **SHA-256 校验和**：
  `81B9FA5E0F544C2B5D2C192483C729CBD6873285778BD1B124A488F2BB26D728`

### 核心特性 (v5.0 / R11 升级重点)
1. **⚡ 一键进入 Bootloader (免按键升级)**：
   内置图形配置工具 `DAPLINK.exe` 新增专属【⚡ 一键进入 Bootloader (UF2 固件升级盘)】按钮；亦可通过在虚拟 U 盘直接修改 `CONFIG.TXT` 写入 `BOOTLOADER` 触发。探针自动向寄存器写入 `0x57`（`DFU_MAGIC_UF2_RESET`）并软复位，直接弹出 `NICENANO`/`NRF52BOOT` 固件盘，彻底告别频繁拆外壳双击硬件 RST 按键！
2. **🔬 实时无线遥测与链路瓶颈诊断**：
   虚拟 U 盘 `STATUS.TXT` 与图形上位机实时更新端到端时延（E2E RTT）、空口往返耗时（Air RTT）、重发率、CRC 统计与自适应瓶颈诊断，通信状态一目了然。
3. **🛡️ 稳固的 Keil 会话重置与自愈机制**：
   基于 100% 成功率验证的会话重置状态机（`WD_SESSION_RESTART_TEST`），当 Keil 烧录结束断开会话或发生通信重连时，自动排空 USB 管道并平滑软复位 WinUSB 管道，彻底消除 `Error: Flash Download failed - Target DLL has been cancelled`。
4. **📡 6.0ms 充裕空口超时**：
   空口 ACK 超时时间精准对齐单包执行周期，避免假超时误判，杜绝空口重发风暴。
5. **🚀 Ultra 240B 极速吞吐 + AFH 自适应跳频**：
   单次空口承载 240 字节大包，4 线 SWD 物理时钟达 3~4 MHz；内置 AFH 4 频点跳频抗 Wi-Fi/蓝牙同频干扰。
6. **🔄 单固件双向自适应 + 数据线/充电线智能识别**：
   主机端与从机端刷入**同一份** `.uf2` 固件。目标端插充电头/充电宝供电（无 USB 枚举）自动保持无线 TARGET 模式；插电脑数据线枚举成功时平滑接管为本地有线下载器。
7. **⚡ P1.13 烧录完成硬件复位**：
   Flash 烧录完成时自动在目标端 `P1.13` 输出 20ms 开漏低电平硬件复位脉冲后释放，支持外部物理复位，亦完全保留原有 SWD 软件复位。

## 🚀 刷录方法 (Drag-and-Drop)

1. 双击开发板上的 **RST 按钮**（若当前固件已支持 R11，可在上位机直接点击【⚡ 一键进入 Bootloader】），板载 LED 变更为呼吸灯模式，PC 弹出名为 `NICENANO` 或 `NRF52BOOT` 的磁盘。
2. 将 `无线DAPLink_一键Bootloader_瓶颈诊断_AFH_R11.uf2` 直接拖拽到该磁盘中。
3. 磁盘自动卸载并完成固件烧写。
4. **务必为两块开发板（主机和从机）刷入完全相同的固件！**
