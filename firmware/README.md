# Firmware Directory / 预编译固件目录

本目录包含经过硬件实测验证的最新正式发布固件，以及源码编译脚本的默认输出目标。

## 📦 推荐量产稳定版固件（v6.0 稳定版 · R4）

经过多设备与实板连续测试验证，本版本作为当前推荐的长期稳定版固件发布。

* **固件文件名**：`无线DAPLink_AFH_固定角色与充电识别_R4.uf2`（或 `wireless_daplink_afh_v6.0.0.uf2`）
* **应用起始地址**：`0x26000`（适配搭载 Adafruit S140 6.1.1 / nice!nano UF2 Bootloader 的 nRF52840 开发板）
* **固件大小**：259,584 字节（507 个 UF2 扇区块）
* **SHA-256 校验和**：
  `D0FAEF6A256DF911387C64D1013F04D8C2B45F8B77EBA2B9E064F98B18183B0B`

### 核心特性 (v6.0 稳定特性)
1. **修复已知问题**：全面修复偶发掉线与会话假死问题，实测连续烧录稳定性最优。
2. **🔄 固定角色防降级 + 数据线/充电线智能识别**：
   - 双板刷入同一份固件。
   - 目标端插充电头/充电宝供电（无 USB 枚举）自动保持无线 TARGET 模式；插电脑数据线枚举成功时平滑接管为本地有线下载器。
   - 固化开机角色，防止 HOST 降级为从机。
3. **⚡ P1.13 烧录完成硬件复位**：
   - Flash 烧录完成时自动在目标端 `P1.13` 输出 20ms 开漏低电平硬件复位脉冲后释放，支持外部物理复位，亦完全保留原有 SWD 软件复位。
4. **🚀 Ultra 240B 大包吞吐 + AFH 自适应跳频**：
   - 单次空口承载 240 字节大包，4 线 SWD 物理时钟达 3~4 MHz；内置 AFH 4 频点跳频抗 Wi-Fi/蓝牙同频干扰。

## 🚀 刷录方法 (Drag-and-Drop)

1. 双击开发板上的 **RST 按钮**，板载 LED 变更为呼吸灯模式，PC 弹出名为 `NICENANO` 或 `NRF52BOOT` 的磁盘。
2. 将 `无线DAPLink_AFH_固定角色与充电识别_R4.uf2`（或 `wireless_daplink_afh_v6.0.0.uf2`）直接拖拽到该磁盘中。
3. 磁盘自动卸载并完成固件烧写。
4. **务必为两块开发板（主机和从机）刷入完全相同的固件！**
