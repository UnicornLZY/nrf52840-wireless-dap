# Firmware Directory / 预编译固件目录

本目录包含经过硬件实测验证的最新正式发布固件，以及源码编译脚本的默认输出目标。

## 📦 推荐量产稳定版固件（v4.4 稳定版）

* **固件文件名**：`uart_latency_packet240_unified_v3_p113_2m_fast_ch80_afh_v2.uf2`
* **应用起始地址**：`0x26000`（适配搭载 Adafruit S140 6.1.1 / nice!nano UF2 Bootloader 的 nRF52840 开发板）
* **固件大小**：291,328 字节（569 个 UF2 扇区块）
* **SHA-256 校验和**：
  `0E18352C8134C9156C4E17B8434F618E2A2356773403EB95D4BCFEA31BFE3C6A`

### 核心特性
1. **Ultra 240B 极速吞吐**：单次空口承载 240 字节大包，批量 Flash 写入无额外分包开销。
2. **AFH 智能自适应跳频**：遇到复杂 2.4GHz Wi-Fi / 蓝牙同频干扰时，在基准信道与伪随机正交信道间毫秒级静默跳转，0 丢包。
3. **免驱虚拟磁盘 ConfigDisk**：插入电脑自动挂载 1MB 虚拟 U 盘，内含 `CONFIG.TXT`、实时遥测 `STATUS.TXT` 以及原生静态链接的图形化配置工具 `DAPLINK.exe`（无外部 DLL 依赖）。
4. **单固件双向自适应 + 数据线/充电线智能识别**：主机端与从机端刷入**同一份** `.uf2` 固件。目标端直接插充电头或充电宝供电（仅 VBUS 供电无 USB 数据枚举）依然保持无线 TARGET 模式，不会误抢占本地有线；仅当真正用数据线接入电脑枚举成功时才平滑接管为本地有线下载器。
5. **P1.13 烧录完成强制硬件复位**：Flash 批量烧录会话完成（`DAP_Disconnect`）时自动在目标端 `P1.13` 输出 20ms 开漏低电平硬件复位脉冲后释放，解决 Keil 未勾选 Reset and Run 或芯片需要物理复位线的场景；同时完全保留原 4 线 SWD 软件复位（不接 `P1.13` 依然正常）。

## 🚀 刷录方法 (Drag-and-Drop)

1. 双击开发板上的 **RST 按钮**，板载 LED 进入呼吸灯模式，PC 弹出名为 `NICENANO` 或 `NRF52BOOT` 的磁盘。
2. 将 `uart_latency_packet240_unified_v3_p113_2m_fast_ch80_afh_v2.uf2` 直接拖拽到该磁盘中。
3. 磁盘自动卸载并完成固件烧写。
4. **务必为两块开发板（主机和从机）刷入完全相同的固件！**
