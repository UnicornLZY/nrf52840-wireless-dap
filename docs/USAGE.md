# 接线与使用详细教程

本项目采用**单固件自由角色**设计，两块 nRF52840 开发板刷入完全相同的固件即可协同工作，不绑定硬件序列号（A 端接目标单片机，B 端插电脑 USB，两块板可随时互换角色）。

---

## 一、引脚定义与硬件接线

![nRF52840 引脚定义图](images/pinout.png)

### 推荐单排直连引脚（目标从机 A 端）

| nRF52840 引脚 | 功能 | 接目标单片机 | 说明 |
|:---|:---|:---|:---|
| **`P0.31`** | SWCLK | `SWCLK` | SWD 时钟线（固件内部限幅 4 MHz） |
| **`P0.29`** | SWDIO | `SWDIO` | SWD 双向数据线 |
| **`GND`** | 信号地 | `GND` | **必须与目标芯片共地** |
| **`P0.02`** | UART RX | `UART TX` | 探针输入 <- 接目标板串口 TX（需串口时连接） |
| **`P1.15`** | UART TX | `UART RX` | 探针输出 -> 接目标板串口 RX（需串口时连接） |
| **`P1.13`** | 目标复位 | `nRESET / NRST` | 目标硬件开漏复位（可选，普通使用可不接） |

### ⚠️ 接线要点与避坑指南

1. **电平标准**：所有 IO 信号均为 **3.3V TTL 电平**，严禁直接连接 5V 单片机（如部分 5V 供电的传统 51 单片机）。
2. **关于板载 `RST` 孔位**：开发板右侧排针中夹在 `GND` 和 `3.3V` 之间的 `RST` 孔位是 **nRF52840 芯片自身的复位引脚**，**绝不能接到目标单片机上**。如果使用多连排杜邦线，可以在该孔插入一个空杜邦胶壳占位，防止插错。
3. **目标端独立供电**：无线模式下，A 端（目标端）请使用 `3.3V` 引脚或外接锂电池供电。**切勿使用 A 端的 Type-C 接口连接电脑或充电头**，否则芯片检测到 VBUS 上电会误判断为电脑端而进入本地有线模式。
4. **未接复位线时**：SWD 只需连接 `SWCLK`、`SWDIO`、`GND` 三根线即可稳定烧录（固件在未接硬件复位线时默认通过 SWD 寄存器执行内核软复位 `SYSRESETREQ`）。

## 二、刷入探针 UF2 固件

新出厂的 nRF52840 开发板通常刷有出厂跑马灯程序。首次使用请按以下步骤刷入本项目发布的稳定固件：

1. 用带数据传输功能的 Type-C 数据线将开发板连接到电脑。
2. **0.5 秒内连续双击开发板上的 `RST` 按钮**（若开发板无物理按键，可用镊子在 0.5 秒内快速短接两次 `RST` 引脚与 `GND`）。
3. 开发板蓝色 LED 进入呼吸灯状态，电脑会弹出一个约 32MB 的可移动磁盘（名为 `NICENANO` 或 `NRF52BOOT`）。
4. 将仓库 [`firmware/`](../firmware/) 目录下的 `uart_latency_packet240_unified_v3_p113_2m_fast_ch80_afh_v2.uf2` 文件直接拖拽复制到该磁盘中。
5. 复制完成后开发板自动完成刷写并重启。
6. **两块开发板均按此步骤刷入同一份固件！**

## 三、免驱虚拟配置盘 (ConfigDisk) 与 GUI 上位机

将电脑端（主机 B 端）插入电脑 USB 后，系统会自动枚举出一个名为 **`DAPLINK`** 的 1MB 虚拟 U 盘：

### 1. 使用内置原生 GUI 工具 (`DAPLINK.exe`)
在虚拟 U 盘根目录中，双击运行 **`DAPLINK.exe`**（30KB 极简纯 Win32 原生应用，无任何第三方依赖）：
* **通信信道 (Channel)**：支持 0~80 频点（默认 80，即 2480 MHz）。若周围 2.4G Wi-Fi 信号极强，可调整频点避开路由器干扰信道。
* **配对码 (Pair Code)**：十进制数字标识。多套无线 DAPLink 在同一工位或教室内使用时，只需为每对设备分配不同的配对码，即可彻底杜绝跨设备串扰。
* **发射功率 (Tx Power)**：支持 4 dBm、8 dBm（默认）等，提供强劲穿墙与抗衰减能力。
* **协议版本 (Protocol)**：
  - `CMSIS-DAP v2 (WinUSB Bulk)`（推荐）：全速免驱，吞吐极高，适配 Keil MDK 5、VS Code (Cortex-Debug)、PyOCD、OpenOCD。
  - `CMSIS-DAP v1 (HID)`：兼容极个别老旧编译环境（如某些只支持 HID 的旧版 IAR）。
* **AFH 跳频 (Adaptive Frequency Hopping)**：勾选启用自适应跳频。在突发强干扰导致连续丢包时，双端自动毫秒级跳转到正交备用频点恢复通信。
* 点击 **“保存并重启”** 后，参数将自动写入 nRF52840 内部 Flash，设备自动重启应用新配置。

### 2. 文本化配置 (`CONFIG.TXT`)
若不在 Windows 环境下，也可直接用任何文本编辑器打开虚拟磁盘中的 `CONFIG.TXT`：
```ini
# Wireless DAPLink Configuration
PAIR_CODE=12345678
CHANNEL=80
TX_POWER=8
PROTOCOL=2
AFH=1
ROLE=0
```
保存文件后，固件会自动检测变动并在 2 秒后写入 Flash 生效。

### 3. 实时状态监控 (`STATUS.TXT`)
打开虚拟磁盘中的 `STATUS.TXT` 可查看当前的实时运行状态：
```text
# Wireless DAPLink Telemetry
ROLE=HOST
PEER_CONNECTED=YES
CURRENT_CHANNEL=80
AFH_ENABLED=1
AFH_HOPS=0
PACKET_MTU=240
SWD_CLOCK=4000000
ACK_RTT_AVG_US=420
```

## 四、智能 LED 指示灯状态说明

开发板板载 LED 提供清晰的连接状态指示：

| LED 状态 | 含义 | 对应动作 |
|:---|:---|:---|
| **慢闪 (1 Hz)** | 搜索配对中 | 正在寻找配对码相同且信道匹配的对端设备 |
| **常亮 (Solid ON)** | 链路连接就绪 | 主从已建立高速 2.4G 链接，处于空闲待命状态 |
| **快闪 (10 Hz 爆闪)** | SWD / 串口传输活跃 | 正在下载固件、单步调试或进行高速串口通信 |

## 五、有线直连与无线模式切换

### 1. 双板无线烧录
1. **A 端（目标端）**：连接目标芯片的 SWD 与 GND，通过 3.3V 引脚供电（不插电脑 USB）。
2. **B 端（电脑端）**：插入电脑 USB，板载 LED 由慢闪变为常亮，表示配对成功。
3. 打开 Keil / VS Code 即可开始无线极速烧录。

### 2. 单板有线直连
1. 将 A 端开发板连接目标 MCU 的 SWD 引脚。
2. 直接用 Type-C 数据线将 A 端插入电脑 USB。
3. 固件检测到本地已挂接目标芯片且连接了 USB，会自动切换为**本地有线高速调试器**（有线直连延迟更低，适合桌面固定工位）。

## 七、无线串口 (CDC UART) 使用说明

* **COM 口分配**：
  - 无线模式下，打开电脑端（B 端）在 Windows 设备管理器中生成的虚拟串口。
  - 有线模式下，打开 A 端直接插入电脑生成的虚拟串口。
* **波特率自适应**：
  默认 `115200 8N1`。支持 `1200` 到 `1000000`（1 Mbps）常用波特率及 `8N1`、`8N2`、`8E1`、`8E2` 格式，上位机更改串口波特率时，探针会自动通过无线帧同步给对端硬件串口。
* **抗丢包机制**：
  串口数据内置 1ms 短帧自适应合包与重传机制，保证在高速连续打印时既不丢字符，又保持极低延迟。
