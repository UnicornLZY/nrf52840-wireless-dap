# 接线与使用教程

本项目采用**单固件自由角色**设计，两块 nRF52840 开发板刷入完全相同的固件即可工作，不绑定硬件序列号（A 端接目标单片机，B 端插电脑 USB，两块板可随时互换角色）。

---

## 一、引脚定义与硬件接线

![nRF52840 引脚定义图](images/pinout.png)

| nRF52840 引脚 | 功能 | 接目标单片机 |
|---|---|---|
| `P0.31` | SWCLK | `SWCLK` |
| `P0.29` | SWDIO | `SWDIO` |
| `GND` | 共地 | `GND`（必须共地） |
| `P0.02` | UART TX | `UART RX`（需要串口时连接） |
| `P1.15` | UART RX | `UART TX`（需要串口时连接） |
| `P1.13` | 目标复位 | `nRESET / NRST`（可选，普通使用可不接） |

- **电平与供电**：IO 信号为 **3.3V 电平**，请勿直接连接 5V 信号。目标端和 nRF52840 板均需正常供电并共地。
- **关于板载 `RST` 孔位**：板载 `RST` 属于探针芯片自身的复位脚，刚好夹在右侧 `GND` 和 `3.3V` 之间。如果使用连排杜邦线，可以在 `RST` 位置插一个空杜邦线头占位，防止相邻杜邦线松动或插错位。
- **未接复位线时**：SWD 至少连接 `SWCLK`、`SWDIO`、`GND` 三根线即可正常烧录（未接 `P1.13` 时默认通过 SWD 软复位 `SYSRESETREQ` 复位目标芯片）。

## 二、刷入探针 UF2 固件

开发板出厂默认程序通常为跑马灯（所有 IO 口 1 秒翻转一次）。首次使用请按以下步骤刷入本项目固件：

1. 用带数据功能的 USB 线将 nRF52840 的 USB 口连接到电脑。
2. **0.5 秒内短接两次 `RST` 到 `GND`**（带按键的板子直接在 0.5 秒内连按两次 `RST` 按键）。
3. 电脑会弹出一个约 32MB 的可移动磁盘（UF2 Bootloader），将本项目 Releases 中的 `.uf2` 固件复制到该磁盘中。
4. 复制完成后开发板会自动重启（两块板都需刷入同一份 `.uf2` 固件）。

> **注意**：固件起始地址为 `0x26000`，依赖开发板原有的 S140 SoftDevice（6.1.1）与 UF2 Bootloader，请通过双击 `RST` 拖入 UF2 的方式升级，不要用编程器整片擦除芯片。

## 三、有线烧录、无线烧录与模式切换

### 1. 有线烧录（单板直连模式）
1. 将 nRF52840 板按引脚图接好目标芯片的 `SWD` 和 `GND`，并给目标供电。
2. 用 USB 数据线将该 nRF52840 板直接连接电脑。
3. 在 Keil 中选择 `CMSIS-DAP Debugger`，进入 `Settings` 选择该探针。
4. `Port` 选择 `SW`，`Max Clock` 选择 `5 MHz`（固件内部自动限幅至 4 MHz）。
5. 确认 `Flash Download` 中已添加对应芯片的烧录算法并勾选 `Reset and Run`，点击 `Download` 即可烧录。

### 2. 无线烧录（双板无线模式）
1. **A 端（接目标板）**：连接目标芯片的 SWD / UART 与 GND，通过 `3.3V` 引脚供电（**A 端不插电脑 USB**）。
2. **B 端（接电脑）**：用 USB 数据线插入电脑，等待 A、B 两端自动配对连接。
3. 在 Keil 中选择 B 端探针，`Port` 选 `SW`、`Max Clock` 选 `5 MHz`，点击 `Download` 即可无线烧录。

### 3. 有线 / 无线切换与供电避坑
- **无线转有线**：直接将 A 端插入电脑 USB，系统会自动切换为有线优先模式（此时 Keil 中改选 A 端探针即可）。
- **有线转无线**：拔掉 A 端 USB 线，保持 A 端 3.3V 独立供电，等待两端无线重连后在 Keil 中改选 B 端探针。
- **交换两块板角色**：先接好目标芯片并给目标上电，再重新上电或重插 USB，固件会在启动时自动探测 SWD 目标并分配角色。
- **重要避坑**：无线模式下，**切勿使用 A 端的 USB 接口插手机充电器供电**，否则可能触发 USB 连接检测而进入本地有线模式。
- **常见排错**：请确保 USB 线支持数据传输（非纯充电线）。若 Keil 识别不到目标芯片，请先检查目标供电、GND 共地及 SWCLK/SWDIO 线序，或尝试将 SWD 时钟降至 `1 MHz` 测试；若偶发无线状态卡顿，重新插拔重启一下电脑端（B 端）即可恢复。

## 五、无线串口（CDC UART）说明

- **端口选择**：有线直连时打开 A 端对应的 COM 口；无线模式下打开 B 端对应的 COM 口（具体 COM 号可在 Windows 设备管理器中查看）。
- **接线方式**：探针 `P0.02 (TX)` 接目标 `RX`，探针 `P1.15 (RX)` 接目标 `TX`，并保持 `GND` 共地。
- **支持参数**：上电默认 `115200 8N1`。支持 `1200`、`2400`、`4800`、`9600`、`14400`、`19200`、`28800`、`31250`、`38400`、`56000`、`57600`、`76800`、`115200`、`230400`、`250000`、`460800`、`921600`、`1000000` 波特率，以及 `8N1`、`8N2`、`8E1`、`8E2` 格式（不支持奇校验、7 数据位及 1.5 停止位）。
- **特性说明**：切换串口波特率前建议暂停持续数据发送；串口无硬件 RTS/CTS 流控，DTR/RTS 信号不会触发目标板复位，同时已屏蔽 1200 波特率误触发 Bootloader DFU。
