# 接线和使用

两板运行同一固件，不绑定板子序列号。目标检测在启动与USB重新接入时进行；需先接线并给目标供电，然后重启或重新接USB。没有电、锁定或不响应SWD的目标不能保证被自动检测到。

| 芯片GPIO | 功能 | 接目标 |
|---|---|---|
| P0.31 | SWCLK | SWCLK |
| P0.29 | SWDIO | SWDIO |
| GND | 共地 | GND |
| P0.02 | UART TX | UART RX |
| P1.15 | UART RX | UART TX |
| P1.13 | 可选目标复位 | nRESET/NRST |

当前按3.3V目标使用，没有目标电压检测与电平转换。两侧串口交叉连接、共地。SWD至少连接CLK/DIO/GND；未接目标复位线时使用SWD软件复位。板载RST属于探针本身。

1. 两块板双击Reset进入UF2盘，都复制本项目同一个UF2。
2. 目标端接好SWD/UART并独立供电；电脑端插电脑。
3. 在Keil中选择该探针（USB VID:PID 239A:80E2，两个物理板序列号不同）。SWD Max Clock可选5MHz，固件限制请求到4MHz；实际输出波形需测量。
4. 配对灯常亮仅代表协议握手完成，不能代替目标识别/烧录验证。
5. 目标端插电脑时有线优先，电脑端整个USB复合设备会隐藏；拔目标端USB后仍需独立供电。切换后Keil/COM句柄可能需要重新选择或打开。

UART冷启动115200/8N1。支持1200、2400、4800、9600、14400、19200、28800、31250、38400、56000、57600、76800、115200、230400、250000、460800、921600、1000000及8N1/8N2/8E1/8E2。配置支持不代表全部档位已实测通过，也不代表无线持续满速无损。

奇校验、7数据位和1.5停止位不支持，无效设置保留上一配置。修改参数前停止收发，等待无线设置应答再继续。DTR/RTS不复位目标；CDC端点就绪即可回传，无需DTR拉高。禁用正常1200波特率关闭COM触发DFU，仍可双击Reset进入UF2。

没有RTS/CTS流控。无线断线、输入长期超过空口能力或主机不读数据时可能丢字节；USB镜像缓存为尽力转发。通信内容没有认证、绑定或加密，不应把该原型用于受保护目标的开放环境。该协议不支持手机蓝牙配对。

使用前以同一目标/工程先测有线，再测近距无线；连续多次烧录、双向UART序号/CRC及UART加烧录并发，随后测距离、恢复、USB切换和长时间待机。
