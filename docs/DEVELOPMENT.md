# 架构与协议设计

本项目在两块 nRF52840 开发板之间构建了一套低延迟无线调试与串口桥接架构，主要设计演进与技术要点如下：

## 核心架构演进

1. **CMSIS-DAP v2 + 私有 2.4 GHz 射频传输**
   摒弃传统高延迟的 BLE NUS 方案，电脑端采用 USB CMSIS-DAP v2（WinUSB Bulk 端点）+ CDC 虚拟串口复合设备，空口采用 nRF52840 原生 `RADIO` 2 Mbps 私有帧协议（频道 40），大幅提升 SWD 小包交互响应速度。

2. **128 字节逻辑包与 4 包滑动窗口（DAP128）**
   支持跨 64 字节 USB 全速 Bulk 事务的自动分片组包与应答重组，支持最多 4 包在途窗口并发与 USB 发送背压控制。

3. **单固件自由角色与有线优先**
   两块开发板运行完全相同的固件。上电或 USB 接入时，通过 SWD Worker 自动探测本地是否连接了目标 MCU：
   - 检测到目标芯片则进入**目标端（Target Role）**；
   - 连接电脑 USB 且无本地目标则进入**电脑端（Host Role）**；
   - 当目标端直接插入电脑 USB 数据线时，自动优先切换为本地有线 CMSIS-DAP v2 模式。

4. **低延迟双向 UART 透传**
   针对串口调试场景优化短帧合包等待（1 ms），并引入 `20 / 40 / 80 / 160 ms` 指数退避应用层 ACK 重传策略，配合连续包序号与接收端去重，保障无线串口数据顺序与可靠性。

5. **安全恢复机制**
   内置无线会话 ID 隔离、CRC 校验与超时恢复机制；当无线链路发生超时或重连时，不会盲目自动重放未知状态的目标芯片写操作，保证目标 Flash 烧录过程安全。
