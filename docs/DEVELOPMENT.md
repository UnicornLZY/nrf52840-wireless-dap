# 架构与协议设计

本项目在两块 nRF52840 开发板之间构建了一套低延迟无线调试与串口桥接架构，核心设计要点如下：

## 核心架构设计

1. **CMSIS-DAP v2 + 私有 2.4 GHz 射频传输**
   摒弃高延迟的 BLE 方案，电脑端采用 USB CMSIS-DAP v2（WinUSB Bulk 端点）+ CDC 虚拟串口复合设备，空口采用 nRF52840 原生 `RADIO` 2 Mbps 私有 ESB 帧协议（默认基准信道 80），大幅提升 SWD 交互响应速度。同时支持随时一键切回 CMSIS-DAP v1 (HID) 兼容老旧 IDE。

2. **Ultra 240 字节逻辑大包与 4 包并发窗口**
   单包有效载荷扩展至 240 字节，针对大块 Flash 写入，空口握手次数与往返轮次减少近 70%，并支持最多 4 包在途窗口并发与 USB 发送背压控制。

3. **AFH 智能自适应跳频 (Adaptive Frequency Hopping)**
   内置空口重发监测机制。当遭遇复杂 2.4GHz Wi-Fi / 蓝牙同频强干扰导致丢包时，主从双机自动在毫秒级内静默跳转到正交备用信道，杜绝 Keil 烧录中断。

4. **单固件自由角色与有线优先**
   两块开发板运行完全相同的固件。上电或 USB 接入时自动探测本地是否连接了目标 MCU：
   - 检测到目标芯片则进入**目标端（Target Role）**；
   - 连接电脑 USB 且无本地目标则进入**电脑端（Host Role）**；
   - 当目标端直接插入电脑 USB 数据线时，自动优先切换为本地有线直连模式。

5. **低延迟双向 UART 透传与 DAP 让道**
   针对串口调试场景优化 1 ms 短帧自适应合包，并引入 `DapActivityGuard` 计数器：在 SWD 烧录活跃期自动降低串口空口上报，全力让渡给 DAP 调试；烧录完成后自动恢复全速高灵敏度传输。

6. **免驱虚拟配置盘 (ConfigDisk 1MB VFS)**
   电脑端自动挂载 1MB 虚拟 U 盘，支持记事本修改 `CONFIG.TXT` 调参、`STATUS.TXT` 实时遥测，并内置 30KB 原生图形化配置工具 `DAPLINK.exe`。
