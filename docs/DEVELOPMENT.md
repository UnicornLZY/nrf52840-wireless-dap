# 开发经过与主线选择

本仓库是原开发工程的可独立构建快照，以用户指定的UART低延迟UF2为主线。未打包个人设备诊断文件、原工程路径、实板完整闪存备份、第三方下载程序或失败固件。

- 早期BLE/NUS原型逐步改为CMSIS-DAP v2 USB Bulk与私有RADIO传输。
- 后续加入目标侧有线优先、UART设置同步、USB应答背压、会话隔离及断链恢复。
- DAP128版本修复了跨64字节USB事务组包/应答，并保留4包在途窗口。
- 自由角色版本取消FICR序列号绑定，启动/USB接入时由SWD worker探测目标。
- 本快照降低UART短帧合包等待，增加20/40/80/160ms确认重试，并保持连续序号与去重。

先前提高worker优先级、扩大DAP窗口及某些8MHz/自动续跑实验曾实板失败或没有收益。V3吞吐和V4中断/COBS重构是另一组开发候选，包含初版失败记录及尚待验证的修正；不能将它们与本主线固件混用或作为本主线的稳定性证据。

贡献时应把协议改动与目标SWD行为分开测试；RF重发不应导致普通目标写入被重复执行。模型、编译、板级波形、主机枚举和真实Flash算法是不同验证层次。请在Issue中给出目标型号、供电/接线、固件哈希、主机工具版本、完整错误文本和首次尝试成功率。
